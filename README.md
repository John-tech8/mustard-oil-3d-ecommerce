3D Organic Mustard Oil E-Commerce Website

A modern 3D product showcase and e-commerce website for an organic mustard oil brand PureHarvest.
This project demonstrates how 3D web technologies can be used to create an immersive online product experience.

The website features an interactive 3D mustard oil bottle viewer, smooth animations, and a clean premium UI design.

🚀 Project Objective

The goal of this project is to build a premium product showcase website where users can:

Explore a 3D rotating mustard oil bottle

Learn about the benefits of organic cold-pressed oil

View product variants

Experience a modern e-commerce style interface

The design is inspired by high-end product websites.

✨ Features

Interactive 3D product viewer

Smooth bottle rotation animation

View Animation button for product interaction

Product showcase with multiple bottle sizes

Farm-to-bottle storytelling section

Customer testimonials section

Clean and premium UI design

Fully responsive layout

Add-to-cart UI simulation

🧴 Product Variants

The website showcases three bottle sizes:

500ml Bottle

1 Litre Bottle

5 Litre Family Pack

Each product includes:

Product image

Price display

Add to Cart button

View Animation button for 3D preview
